# Visual Reference Notes

The reference image is treated as a visual target only. It is not used as a texture or source asset.

## Dense Woven Spherical Knot

The object should read as one continuous closed ribbon compacted into a spherical woven orb. It should feel mathematically coherent rather than like separate decorative bands.

## Outward-Flared Ribbon Edges

The surface is wide and flattened, with lips that curl outward from the center of the sphere. This helps the silhouette form bright pinched tips while preserving the feeling of a ribbon.

## Oil-Slick Longitudinal Gradients

Color should travel primarily along the length of the ribbon. The palette avoids plain HSV rainbow bands and instead mixes jewel-like magenta, violet, indigo, cyan, teal, emerald, copper, gold, rose, and orange.

## Implied Fibre-Bundle Structure

Each ribbon contains many fine aligned sub-strands. These are shader lines embedded in the surface, not separate sparks, hairs, or flames.

## Brilliant White Diamond Light

The center of the knot contains a bright crystalline white light. It should influence the surrounding ribbon through core glow, specular-looking highlights, sparkles, and bloom.

## Black Background

The background remains black so the luminous geometry carries the scene with high contrast.
